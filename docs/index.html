⚙️ Platform Core Engines

NB Platform is built around four proprietary foundational engines that guarantee zero dual-active login fraud, robust data isolation, and instant real-time reactivity:

1. Single-Session Enforcement & Real-time Displacement

To prevent credential sharing and attendance manipulation, every user is restricted to strictly one active session. New sign-ins instantly invalidate older sessions via Redis. Connected clients are notified via SSE (session:displaced) and Socket.IO, terminating superseded sessions in < 50ms without requiring page reloads.

2. 5-Action Scoped RBAC Matrix

Granular access controls enforce permissions across five distinct verbs: CREATE, READ, UPDATE, DELETE, and APPROVE. Records are filtered dynamically by employee hierarchy: NONE, SELF, INSTITUTE, or UNIVERSITY.

3. Double-Layer AES-GCM Transport Security

In addition to standard TLS/HTTPS, sensitive mobile-to-server payloads undergo client-side AES-GCM payload encryption with dynamic nonces (transport_crypto) before transmission, mitigating man-in-the-middle sniffing on public Wi-Fi or compromised networks.

4. Multi-Tenant Modular Licensing Gates

Each organizational entity or subsidiary (sub-org) is licensed selectively for HRMS, CRM, or ERP. Middleware guards (requireModuleLicense) prevent unauthorized module access at both route and database query levels.
