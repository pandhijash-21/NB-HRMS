Security, Authentication & RBAC Matrix

Comprehensive specification of the authentication lifecycle, strict single concurrent session enforcement, real-time eviction push, the 5-action scoped RBAC permission engine, and transport encryption.

🚫
Single Active Session

Zero concurrent logins for the same account. New login instantly evicts previous devices in real time (<50ms).

🛡️
5-Action Scoped RBAC

Granular verbs (CREATE, READ, UPDATE, DELETE, APPROVE) scoped by SELF, INSTITUTE, or UNIVERSITY hierarchy.

🔐
Double AES-GCM Transport

Client-side payload encryption prior to network transmission, mitigating proxy interception.

1. Single-Session Enforcement & Real-Time Displacement

To prevent buddy punching, attendance spoofing, and credential sharing across devices, the platform implements strict single-session exclusivity:

Session Displacement Sequence Diagram
📱 Device B Logs In
➔
🔑 Mint New JWT
➔
⚡ Overwrite Redis session:<userId>
➔
📡 Push session:displaced via SSE & Socket.IO
➔
🚪 Device A Instantly Signed Out
Layer / Component Behavior & Enforcement Mechanism Latency / Timing
Redis Session Key Stores session:<userId> = <jwt_token>. On new login, old key is overwritten and prev_session is wiped immediately (zero grace period). Atomic, immediate (< 2ms)
Server-Sent Events (SSE) Backend calls sseService.toUser(userId, 'session:displaced', ...). Web EventSource receives event and triggers signOut(). Sub-second (< 50ms)
Socket.IO Gateway Backend calls emitSessionDisplaced(userId, ...) to room user:<userId>. Mobile/Flutter socket triggers UnauthorizedGate.notify(). Sub-second (< 50ms)
API Guard (requireAuth) If an incoming request presents a displaced JWT (where sessionToken !== token), the API immediately rejects it with HTTP 401. Synchronous on request

2. Persistent Login ("Remember Me") Lifecycle

The platform distinguishes between transient standard logins and persistent trusted device logins:

Feature Standard Login (Remember Me Unchecked) Remember Me Active
JWT Expiration 8 hours (expiresIn: '8h') 30 days (expiresIn: '30d')
Redis TTL 8 hours (28,800 seconds) 30 days (2,592,000 seconds)
Sliding Window Extended by 8 hours on each authenticated API call. Extended by 30 days on each authenticated API call.
App Restart Behavior Bounces to login screen once 8-hour token expires. Seamlessly keeps user authenticated into dashboard; auto-renews.
Displacement Handling Session evicted; credentials not stored. Session evicted; saved credentials automatically purged to prevent fighting the new active session.

3. 5-Action Scoped RBAC Engine

Permissions are structured as a 2D matrix of modules and action verbs, augmented with organizational scope filters:

Action Verb Scope Filter Functional Meaning Example Enforcement
CREATE Module-level Ability to author new records. Creating a new purchase order or leave application.
READ SELF / INSTITUTE / UNIVERSITY Visibility boundary. SELF sees own salary; INSTITUTE sees campus salary; UNIVERSITY sees all.
UPDATE SELF / INSTITUTE / UNIVERSITY Ability to edit existing records. Editing draft DPR or updating lead notes.
DELETE Module-level Ability to purge or soft-delete records. Deleting a canceled tender or unused project item.
APPROVE Hierarchical Sign-off authority. Approving leave requests, purchase orders, or employee profile changes.
