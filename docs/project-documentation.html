1. Overview

NB HRMS is a multi-tenant CRM + HRMS + ERP + Collaboration platform forked from a university HRMS. The product database is nb_crm_db and must never share a connection with the college hrms_db.

Primary client

Flutter app nb_crm_flutter (web, Android, desktop). Routes such as /admin/earth and CRM/ERP live here.

API

Express 5 + Prisma 6 on port 4000. REST under /api, health at /health, sockets for chat/meet.

Legacy UI

Next.js frontend/ remains as a reference HRMS UI. New work ships in Flutter.

2. Architecture

Request path from a signed-in admin to Postgres and sidecars.

Login→JWT in Redis session→ Module license (HRMS/CRM/ERP)→ RolePermission or OrgAdminPermission→ Prisma / Socket.IO / LiveKit

5. Auth and RBAC

Login surfaces

  • Company / tenant: Flutter /login → POST /api/auth/login
  • Superadmin: Flutter /superadmin/login with portal: "superadmin" or header X-Auth-Portal
  • Also: logout, /api/auth/me, change-password, OTP /api/otp

Session model

  • JWT signed with JWT_SECRET
  • Redis key session:{userId}, one active login, ~8h sliding TTL
  • If Redis is down, login fails closed (503) — not a bare JWT
  • Tenant ADMIN uses OrganizationAdminPermission
  • Other roles use RolePermission per SystemModule

Permission actions: READ, WRITE, APPROVE, DELETE, EXPORT. Org product license is stored in organization tagLine JSON such as ["HRMS","CRM","ERP"]. Route groups enforce requireModuleLicense.

11. Security

  • Helmet + CORS allowlist (localhost, Vercel, Netlify, crm.nbdeveloper.co.in)
  • VPN/proxy block in production (/vpn-gate)
  • AES-256 at rest for Aadhaar/PAN; transport AES-GCM between Flutter and API
  • RBAC on every mutating module; tenant license gates HRMS/CRM/ERP routers
  • Cloudinary uploads via memory multer; collab static files behind auth

12. Chat, Meet, and tracking

Chat uses Socket.IO + REST /api/chat. Meet uses LiveKit tokens from /api/meetings plus optional Whisper captions. Field staff send GPS to /api/tracking; admins replay trips in tracking-hub.

14. Operations checklist

  1. Postgres nb_crm_db migrated (npx prisma migrate deploy).
  2. Redis up — otherwise nobody can log in.
  3. Open system health or http://localhost:4000/system-health.
  4. Confirm GET /health shows redis/cloudinary/whisper.
  5. Flutter debug: Local chip → login → NB Earth / CRM / ERP as licensed.
  6. Grant GOOGLE_EARTH on the tenant ADMIN matrix for Earth.
