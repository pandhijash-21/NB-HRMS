NB Earth & Geospatial Telemetry

A command-center visualizer uniting interactive 3D WebGL planet rendering, infrastructure project geospatial markers, live mobile worker GPS tracking, geofence polygon enforcement, and historical breadcrumb playback.

🌐
3D Earth Globe

Interactive WebGL sphere with realistic day/night textures, cloud layers, and camera targeting.

📍
Infrastructure Asset Pins

Geocoded project sites, road contracts, real estate towers, and quarry concessions pinned globally.

🛰️
Live Tracking Hub

Real-time mobile worker positions, active trip polylines, battery telemetry, and geofence alerts.

1. 3D WebGL Globe Visualizer

Rendered natively in Flutter via flutter_earth_globe with asset fallbacks ensuring offline usability:

Layer Component Asset Source / Engine Behavior & Performance Optimization
Base Earth Surface 2K/4K diffuse surface map with local asset fallback (assets/images/earth/). Hardware-accelerated texture mapping; cached in memory for zero-lag spinning.
Atmospheric Glow Custom WebGL / Canvas shader layer. Dynamically shifts color based on elevation and pitch angle.
Point of Interest (POI) Pins Vector billboard markers rendered with depth sorting. Pins scale dynamically; clicking reveals project details, photos, and current workforce count.

Stop & Idling Detection

When GPS coordinates remain within a 25-meter radius for greater than 5 minutes, the system marks a stationary stop event, logging location name, duration, and engine idle status.

Geofence Compliance Monitoring

Polygon geofences define approved project boundaries. If a tracked employee departs the designated zone during working hours, a real-time notification alert is posted to site supervisors.
