Documentation / Realtime & Clients / Chat, Meet & AI Whisper

Collaboration, Video Conferencing & AI Transcription

A real-time communication platform combining enterprise team messaging, LiveKit WebRTC video meetings with knocking rooms, self-hosted Faster-Whisper AI speech-to-text inference, and a dual-transport event broadcasting bus.

💬
Omnichannel Chat

Direct messaging, project channels, threads, reactions, file attachments, and typing indicators.

📹
NB Meet (LiveKit WebRTC)

Video conferencing, screen sharing, knocking waiting room, host moderation, and interactive board.

🎙️
Faster-Whisper AI STT

Self-hosted Python STT microservice on port 8095 generating automated multi-lingual transcripts.

1. NB Meet & LiveKit WebRTC Video Architecture

Built on LiveKit WebRTC infrastructure for high-definition, low-latency video meetings across mobile, desktop, and web:

Feature Technical Implementation Access & Moderation Control
Knocking / Waiting Room Guest tokens route users to waiting:<participantId> room. Host receives waiting_knock event. Host clicks Admit or Deny via emitJoinDecision().
Interactive Whiteboard Vector stroke paths broadcast via Socket.IO (board_draw, board_clear). Collaborative real-time sketching during design review sessions.
Screen Sharing MediaStream track capture (Web displayMedia or Android MediaProjection). Any participant granted presenter permission.
Room Moderation Dispatches meeting_moderation events (mute audio, stop camera, kick peer). Restricted to Meeting Host or Company Admin.

2. Self-Hosted Faster-Whisper Speech-to-Text Engine

To ensure complete data privacy without sending audio to third-party cloud APIs, the platform includes a self-hosted Whisper microservice:

AI Speech Transcription Pipeline
🎙️ Live Audio Stream
➔
📦 Audio Chunk Ingestion (:8095)
➔
🧠 Faster-Whisper Model
➔
📜 Text Utterance & Timestamp
➔
📡 Socket.IO (meeting_transcript)
➔
🗄️ PostgreSQL Meeting Archive

The microservice is located in /whisper/server.py and runs a FastAPI server wrapping CTranslate2-optimized Faster-Whisper models:

  • Port & Endpoints: Listens on http://localhost:8095/transcribe and /health.
  • Language Detection: Automatically detects spoken language or accepts hints (e.g. English, Hindi).
  • Speaker Alignment: Utterance metadata binds speaker participant ID, name, start time, and text.

3. Real-Time Event Broadcasting Matrix

The platform uses a dual-transport event architecture to guarantee instant real-time synchronization:

Event Name Transport Payload Scope Client Action
session:displaced / session_displaced SSE + Socket.IO user:<userId> Instant session eviction in <50ms when account signs in elsewhere.
crm_unit_update Socket.IO Global broadcast Updates unit inventory grid in TowerUnitsScreen without reload.
crm_update Socket.IO Global broadcast Triggers lead timeline and stage refresh in CRM Pre-Sales dashboard.
erp_update Socket.IO Global broadcast Notifies procurement and project managers of new GRN or PO approvals.
new_message Socket.IO channel:<channelId> Appends chat message to active conversation with audio alert.
permissions_updated SSE + Socket.IO Global broadcast Hot-refreshes user permission cache without logging out.
