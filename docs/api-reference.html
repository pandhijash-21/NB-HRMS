REST API & Real-time Endpoint Reference

Exhaustive catalog of REST endpoints, authentication protocols, headers, parameters, and payloads across HRMS, CRM, ERP, Realtime Events, and Meet infrastructure.

💡
Authentication Header: All protected endpoints require a Bearer token: Authorization: Bearer <jwt_token>. EventSource SSE streams accept the token as a query parameter (?token=<jwt_token>).

1. Authentication & Session Endpoints

Method Endpoint Request Body / Params Description & Response
POST /api/auth/login { identifier, password, portal?, platform?, rememberMe? } Authenticates user. Returns JWT and user profile. Enforces single concurrent session via Redis eviction.
GET /api/auth/me None (Bearer header) Validates current JWT, checks email verification and emergency contact status. Refreshes JWT if user has active trip.
POST /api/auth/logout None Explicitly invalidates Redis session key and disconnects active real-time channels.
POST /api/auth/change-password { currentPassword, newPassword } Changes account password and requires fresh re-authentication.

2. Real-Time Telemetry & Event Streams

Method Endpoint / Protocol Payload / Query Description
GET /api/events/stream (SSE) ?token=<jwt> Persistent Server-Sent Events stream. Emits session:displaced, permissions_updated, push_notify.
WS /socket.io (Socket.IO) auth: { token: <jwt> } Bidirectional WebSocket for team chat, LiveKit meeting events, inventory status updates, and GPS location streams.

3. HRMS & Attendance APIs

Method Endpoint Parameters Description
POST /api/attendance/punch { latitude, longitude, source, faceVerified? } Records biometric attendance punch. Validates geofence coordinates against project boundaries.
GET /api/attendance/my-summary ?month=<YYYY-MM> Retrieves monthly attendance calendar: present, absent, half-days, missed punches, and overtime hours.
POST /api/leave/apply { leaveTypeId, fromDate, toDate, reason } Submits leave application into the multi-tier approval workflow.
GET /api/payroll/my-payslips ?year=<YYYY> Returns itemized 7th Pay Commission monthly salary statements.

4. CRM Pre & Post-Sales APIs

Method Endpoint Parameters Description
GET /api/crm/leads ?stage=<stage>&search=<q>&page=<n> Fetches leads scoped by agent allocation and organizational permissions.
POST /api/crm/leads { name, phone, email, project, source } Creates lead and triggers dynamic round-robin assignment.
POST /api/crm/leads/:id/call { agentExtension } Dispatches click-to-call command to Elision / Greeter PBX telephony server.
PATCH /api/crm/units/:id/status { status: 'AVAILABLE'|'BLOCKED'|'BOOKED' } Updates real estate unit status and broadcasts crm_unit_update via Socket.IO.

5. ERP & Infrastructure APIs

Method Endpoint Parameters Description
GET /api/erp/projects ?status=<status> Returns active civil engineering and real estate construction projects.
GET /api/erp/boq/:projectId None Retrieves hierarchical Bill of Quantities item master with rate analysis.
POST /api/erp/purchase-orders { vendorId, items: [...], totalValue } Generates procurement purchase order against approved material requisitions.
POST /api/erp/dpr { projectId, date, labor, equipment, items, photos } Submits Daily Progress Report. Supports multi-draft offline synchronization.
